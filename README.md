# Hi, I'm Madhumitha :)

I'm a Senior Machine Learning Engineer building agentic AI systems, from RAG pipelines and multi-agent frameworks to memory-aware assistants and, most recently, the infrastructure to evaluate whether these agents actually behave correctly rather than just sound correct. I open-sourced AgentRubric, a trajectory-scoring framework for LLM agents, born out of building evaluation pipelines in production.

I am deeply interested in Computational Neuroscience + Reinforcement Learning + JAX as a path to rethinking how we build intelligent systems. By studying how the brain learns, adapts, and generalizes, I aim to bring those principles into machine learning to create systems that are more fluid, robust, and truly intelligent, with the long term goal of contributing to the creation of - ‘AGI’ :)

I run JAX-RL-Lab, a public repository of daily JAX and RL implementations, and write about the process on my blog, "Learning JAX as a Senior ML Engineer," documenting what it actually looks like to rebuild fundamentals from zero while working full time. I also teach data structures and algorithms on YouTube, because explaining an idea clearly is usually the fastest way to find out if you actually understand it.

My longer term interest is computational neuroscience as a lens on intelligence itself. I study how biological systems learn, adapt, and generalize with so little data, and ask what of that is missing from how we currently build ML systems. That curiosity has taken concrete form outside of work too. I built a game controlled by my own brain signals, and I built SilentVoice, a sign language translating glove combining embedded sensors with ML gesture classification, published as an open source Instructable. Electronics and 3D printing are how I turn ML ideas into things I can actually hold. I think the gap between how brains learn and how our models learn is where a lot of the next real progress, toward something worth calling general intelligence, will come from.

Outside of work, I enjoy blending cinematography and technology. I directed the world’s only short film on Algorithms and Data Structures, because I believe the best technology is also a story worth telling.
